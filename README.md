# ZKTeco Attendance System (Next.js + Express + MongoDB)

Login: admin / admin

## চালানোর নিয়ম
1. MongoDB local এ চালু রাখুন (port 27017)
2. Backend:
   cd backend && npm install && npm start
3. Frontend (নতুন টার্মিনালে):
   cd frontend && npm install && npm run dev
4. ব্রাউজারে http://localhost:3000 খুলুন

## সেটিং
backend/.env ফাইলে ZK_IP, ZK_PORT বদলান।
